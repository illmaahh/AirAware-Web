# Design direction

The visual system intentionally avoids a conventional ChatGPT-looking dashboard.

Signature interaction:
- 3D Atmosphere Core in the hero
- smooth section transitions
- motion-reduced fallback through native CSS/Framer Motion behavior
- dark Climate Lab against pale Air Lens
- data cards shaped like an observatory/control-room interface
- "project journey" expressed through product architecture rather than a text-heavy landing page

The 3D scene is procedural, so no image assets or copyrighted stock imagery are required.
